# Interaction inventory

This inventory records the current user-visible state of Atlas interactions.
It prevents a styled control from implying capability that does not exist yet.

## Available now

- Public navigation and sign-in/register routes.
- Protected workspace navigation, browser history, and sign-out.
- Catalogue search, sort, card/table choice, infinite loading, and profiles.
- Planet profile loading, unavailable-record, and protected-route states.
- External NASA Archive, Kepler/K2 mission, and NASA media links.

## Planned and deliberately unavailable

- Advanced catalogue search.
- Saved explorations and workspace history.
- Query builder, population plotter, target briefings, exports, and API access.
- JWST and TESS follow-up integrations.
- Field-level provenance browsing and the visual-model specification viewer.

Planned work uses a disabled control labelled `PLANNED`; it does not open a
toast or an empty screen. The source integration and tool issues remain the
authoritative delivery plan.
